Frame Scape

A first-person shooter inspired by Halo and Warframe that runs in a web browser from plain static files, and stays playable on very old hardware.

Play the game

Needs a browser with WebGL. Mouse and keyboard work; Xbox controllers are supported.

What this project is

Frame Scape starts in a dark corridor, fights through a hangar and a canyon, and opens into a procedural wilderness with biomes, an ocean, a day and night cycle, harvesting, fishing and a giant kaiju. You collect credits, power and mod cards to upgrade your weapons, frame and two companions: a combat drone and a beast.

There is no build step and no server code. Textures are drawn on a canvas, sound is synthesized with WebAudio, and the only outside dependency is three.js r152.2 from a CDN.

How it is developed

The game is built in AI-assisted patch sessions. One text file, framescape.flat.txt, holds every requested feature, groups them into dependency-ordered chunks (CH-01 and up) sized for a single AI session, and records the history of what shipped. Each session finishes one chunk and returns the updated game plus the updated planner.

Status: v0.8.2 with the CH-06 container patch and the CH-25.5 drone-damage hotfix. Next planned chunk: CH-07, hangar bay expansion.

Run it locally

Browsers block ES modules opened straight from disk, so serve the folder:

python -m http.server 8000

Then open http://localhost:8000/.

Working on it with an AI

  • Point the AI at the repository and tell it to read AGENTS.md and the top of framescape.flat.txt first.
  • Ask it to "run plan.next". It will pick up the next chunk, change the code in frame-scape/, and update the planner file.
  • Gameplay numbers belong in assets.js; code changes carry /* CH-NN.X */ markers.
